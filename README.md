# Pusty Wymiar - Fabric 1.20.1

Fabric mod dodający pusty wymiar i komendy dla operatorów:

- `/void` - przenosi wykonującego gracza do pustego wymiaru.
- `/overworld` - przenosi wszystkich graczy z pustego wymiaru z powrotem do Overworld.

Wymaga Fabric Loader i Fabric API dla Minecraft 1.20.1 oraz Javy 17.
